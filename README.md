## 原典確認・保留事項

1. **1981年8月21日の『熱風』最終公演会場**：公式HISTORYでは那覇市民会館、別の公演資料では沖縄県労働福祉会館。公式HISTORY表記で仮登録、差異を注記。要原典照合。
2. **1982年7月1日『御意見無用’82』初日の会場**：公式HISTORYでは「埼玉会館」、別の公演資料では「神奈川県立青少年センター」。公式表記で仮登録、差異を注記。要原典照合。
3. **1986年12月18日 静岡市文化会館**：当日は延期で、開催済みではありません。1987年1月に振替公演があったことは二次資料に記録されていますが、**振替の正確な日付が未確認**のためカレンダーにはまだ登録していません。実施公演数の見かけ上の数値に注意してください。
4. **1983年ネムスプリングフェスティバル関連**：全国8公演とされますが、日付・会場を確認できるのは1983年5月1日の合歓の郷のみです。残り7件は架空の日付を付けず保留。
5. 1981〜1985年のその他の単独・イベント公演、メディア出演、各作品発売日については一部未収録です。**全記録網羅ではありません。**

## 公開サイトへの反映

1. ZIPを展開し、GitHubリポジトリの `data/` フォルダーに `events.js`、`events.json`、`events.csv` の3ファイルをアップロードして既存ファイルを置き換えます。
2. リポジトリの最上位フォルダーに `README.md` をアップロードし、同名ファイルを置き換えます。
3. Commit changes を押した後、GitHub Pagesを再読み込みしてください。サイトが読み込むのは `data/events.js` です。

### 管理ツールについて

`admin.html` はブラウザー内でイベントを編集し、JSON/JSをダウンロードするオフライン編集補助ツールです。**GitHubへの自動保存やログイン保護はありません。** 公開ページ上に入力した情報はGitHubのデータファイルへ自動反映されません。

### データと引用

- 既存記録に付与されたIDを維持。
- 追加行には出典URLを保持。
- 出典に基づく日付・会場情報と、一次資料での照合完了は分けて扱います。
- 同日同会場の昼夜2回公演は、出典確認後それぞれ固有IDで登録します。
- 作品発売日、ライブ開催日、放送日は区別します。
- すべての公演にセットリストを付与する方針ではありません。
