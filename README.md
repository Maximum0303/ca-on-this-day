## 更新方法

1. GitHubの `ca-on-this-day` リポジトリを開く。
2. `data` フォルダーに入り、`Add file` → `Upload files` を選ぶ。
3. 本ZIPを展開し、その中の `data` フォルダーの**中にある** `events.js`、`events.json`、`events.csv` の3ファイルをアップロード（同名ファイルを上書き）。
4. `Commit changes` を実行する。
5. READMEはリポジトリ直下（トップ階層）へアップロードして更新する。
6. ブラウザーでサイトを開いて `Ctrl+F5` で更新確認する。

公開サイトは `data/events.js` を参照。`events.json` はデータの正本、`events.csv` はExcel等での確認用です。3つは同じイベントID・件数に揃えています。

公開サイトのURL： https://maximum0303.github.io/ca-on-this-day/
