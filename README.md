## GitHub Pages更新方法

1. ZIPを展開して、リポジトリ `data` フォルダーの `events.js` / `events.json` / `events.csv` を上書き。
2. リポジトリのトップ階層に `README.md` を上書き。
3. Commit changes して公開データを確認。
4. 画面が旧件数なら `Ctrl + F5` で再読み込み。

`index.html` / `app.js` / `styles.css` は変更不要です。
