## 出典・確認状況

以下の各年ページの **TV出演データ・ラジオ出演データ**で、年月日が確認できる記録を採用しました。

- 1986年：https://w.atwiki.jp/cavc/pages/27.html
- 1987年：https://w.atwiki.jp/cavc/pages/28.html
- 1988年：https://w.atwiki.jp/cavc/pages/29.html
- 1989年：https://w.atwiki.jp/cavc/pages/50.html
- 1990年：https://w.atwiki.jp/cavc/pages/51.html
- 1991年：https://w.atwiki.jp/cavc/pages/52.html
- 1992年：https://w.atwiki.jp/cavc/pages/53.html

- cavcは**非公式資料**です。追加178件はすべて `verification: secondary` とし、放送局・番組の公式記録で確認したという意味にはしていません。
- 原則として出演・トーク・ライブ中継・本人映像がある放送を対象としています。同じライブの実施日と放送日は別イベントであり、両者を混同していません。
- 放送日が**年のみ・月のみ・空欄**のレコードは、不明な日を推測せず登録対象から外しました。
- 1986年ラジオ「FMライブハウス」はcavcの日付が「'86.01,11」と記載されているため、確実な日付の照合までは保留しています。
- **1989年7月20日「ザ・ベストテン」**は、cavcの局名欄が「テレビ朝日」となっており疑義が残ります。放送局はデータ上「放送局要照合」とし、確定していません。
- 1989年1月14日「CHAGE&ASUKA 武道館 ENERGY LIVE」は、cavc備考の収録日表記に放送日と矛盾する記述があるため、日付以外の公演詳細は確定しません。
- 1987年10月1日・8日の「新選組」は、ASKAがドラマに出演した記録で、音楽番組ではありません。
- 番組名は可能な限りcavcの記載を維持し、レコード備考では内容を短く要約しています。著作物に当たるセットリストや放送曲一覧は転載していません。
