- リポジトリ：<https://github.com/Maximum0303/ca-on-this-day>
- 運営：Maximum（非公式ファンサイト）

### 管理画面を公開サイトから切り離す手順（2026年11月18日）

GitHub Pagesに設置された `admin.html`、`admin.js`、`admin.css`、`admin-v200.css` は公開アクセスできてしまうため、**リポジトリの `main` ブランチから4ファイルを削除**します。編集機能は、PCに保存したオフライン専用HTMLで利用します。**管理用HTMLをリポジトリにアップロードしないでください。**

1. GitHubで最新の `data/events.json` をダウンロードします。ローカル編集ツールには配布時点の3,844件が同梱されているため、その後の更新に備えて作業開始のたびに最新JSONを読み込む必要があります。
2. PC保存の `C&A_ローカル管理ツール_Ver2.0.1.html` をChrome/Edgeで開き、「JSONを読み込む」で最新データに置き換えます。
3. 「元データをバックアップ」でバックアップZIPを保存します。
4. 内容を編集後、「更新用3ファイルZIPを保存」からJSON・JS・CSVの3点を取得し、更新元のデータ版と件数を確認します。
5. GitHub上の `data/` に3ファイルをアップロードしてCommitします。編集だけではGitHubのデータは変わりません。

`data/events.json` が正本です。CSVは照合用で全属性は復元できません。公開リポジトリの過去のコミット履歴には、削除済み管理画面のソースコードが残る場合があります。リポジトリの書き込み権限がない第三者は公開データを変更できません。

### 編集・照合の原則

- 同日・同会場でも昼夜別公演など別の出来事は別IDを保持します。
- `postponed`（延期）、`cancelled` / `canceled`（中止）を公演実施済みとして扱いません。
- `scheduled`（開催予定）は日付が経過しても自動で「開催済み」に断定せず、実施確認を待ちます。
- `verification: primary` は公式などの一次資料で確認できたもの、`secondary` は二次資料に基づくものとして区別します。
- 出典URLとIDを維持し、根拠なく削除・上書きしません。
- 開催日と放送日、発売日を区別し、日付不明の出来事を推測で登録しません。
- 「記録・記念日」と「デビュー前・アマチュア活動」は別分類です。
- Chage・ASKAの誕生日、8月25日のデビュー周年は画面上で自動表示し、毎年の記録を機械的には増やしません。
