## 資料の性質と登録基準

新規137件は、非公式アーカイブの「CHAGE and ASKA 映像情報メディア管理センター（cavc）」の各年のテレビ・ラジオ出演表で**具体的な放送年月日が確認できるもの**のみを採用しました。各レコードは `verification: secondary` とし、一次資料未照合を備考に記載しています。**放送局・番組の公式記録で確定済みという意味ではありません。**

- 出演者本人の番組出演・ライブ中継、スタジオライブなどを対象にしました。
- 同じ日の異なる番組は別記録とし、日付は**公演収録日ではなく放送日**としました。
- Chageと石川優子による1984年「ふたりの愛ランド」関連出演は `artist: Chage` として登録しました。
- ASKAの1984年ドラマ「友よ」出演は `artist: ASKA` としました。
- 日付が「1984年5月」「1985年」のように月・年までしか分からない記録は追加していません。
- 日付・局名に矛盾や疑義がある記録（例：1984年「LIVE G」の4月10日／13日、1985年のLIVE AID放送日の記述）は今回保留しています。また、放送内容が確認できない1979年12月31日の記録も保留しました。
- 番組名の表記は資料の主旨を保って整理しています。セットリストの網羅は行っていません。
